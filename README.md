# PulseRoadmap

PulseRoadmap is a B2B SaaS-style product operations platform for product teams.

The first version will be a frontend-only demo dashboard with realistic product data. After the UI foundation is clear, the project can grow into a full-stack app with a FastAPI backend, PostgreSQL database, authentication, and AI-assisted workflows.

## First MVP Scope

- Dashboard overview
- Customer feedback preview
- Roadmap progress preview
- Bug triage summary
- Release status summary
- AI insights panel

## Planned Tech Stack

- Frontend: React, Vite, TypeScript
- Styling: Tailwind CSS
- Backend later: FastAPI, SQLAlchemy
- Database later: PostgreSQL
- Deployment later: Docker Compose

## Project Structure

```text
apps/
  web/      Frontend application
  api/      Backend application, added later
docs/       Planning notes and product documentation
infra/      Docker and deployment configuration, added later
```
